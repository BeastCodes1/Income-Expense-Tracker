# Welcome to your Expo app 👋

This is an [Expo](https://expo.dev) project created with [`create-expo-app`](https://www.npmjs.com/package/create-expo-app).

## Get started

1. Install dependencies

   ```bash
   npm install
   ```

2. Start the app

   ```bash
   npx expo start
   ```

In the output, you'll find options to open the app in a

- [development build](https://docs.expo.dev/develop/development-builds/introduction/)
- [Android emulator](https://docs.expo.dev/workflow/android-studio-emulator/)
- [iOS simulator](https://docs.expo.dev/workflow/ios-simulator/)
- [Expo Go](https://expo.dev/go), a limited sandbox for trying out app development with Expo

## Mobile finance features

The mobile app includes the desktop dashboard's main features:

- Monthly income, expenses, net and projected balances, and spending insights
- Search, add, edit, and delete transactions
- Monthly category budgets with spending progress
- Recurring income and expense schedules
- Sign in, account creation, password reset, and sign out
- A saved light/dark theme preference

The app reads and writes data directly through Supabase using the signed-in
user's session and the database's row-level security policies. Apply
`../supabase/schema.sql` in the Supabase SQL Editor to set up the transaction,
budget, and recurring-transaction tables and policies.

For account confirmation and password reset links, configure the mobile app's
redirect URL in Supabase Authentication URL settings. The app uses the `mobile`
URL scheme from `app.json`; when testing in Expo Go, use the redirect URL
generated for that Expo Go session as well. with Expo

You can start developing by editing the files inside the **src/app** directory. This project uses [file-based routing](https://docs.expo.dev/router/introduction).

## Get a fresh project

When you're ready, run:

```bash
npm run reset-project
```

This command will move the starter code to the **example** directory and create a blank **src/app** directory where you can start developing.
